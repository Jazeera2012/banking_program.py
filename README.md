# 🏦 Python Banking Program

A beginner-friendly interactive banking program built with Python.

## ✨ Features

- 💰 **Show Balance** — View the current account balance.
- 📥 **Deposit** — Add money to the account.
- 📤 **Withdraw** — Withdraw money if sufficient funds are available.
- ✅ **Input Validation** — Reject invalid and non-positive amounts.
- 🛡️ **Error Handling** — Handle non-numeric input using `try/except`.
- 🔄 **Interactive Menu** — Continue using the program until the user chooses to exit.

## 🛠️ Technologies

- Python
- Functions
- `while` loops
- Conditional statements (`if`, `elif`, `else`)
- User input and formatted output
- Exception handling (`try/except`)

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python banking_program.py
```

If your system uses `python3`, run:

```bash
python3 banking_program.py
```

## 📋 Menu Options

1. Show Balance
2. Deposit
3. Withdraw
4. Exit

## 📌 Notes

This project is an educational simulation of basic banking operations. It does not connect to a real bank, save account data permanently, or process real financial transactions.
